# 第二阶段：独立动作服务

当前为**隔离执行服务**。已验证真实 ARDY 权重生成与 HTTP 受理/拉取/隔离确认；未连接正式 Unity/Udon 姿态接收器。因此 `/health.execution_ready` 固定为 `false`，正式插件继续使用原动作系统。

## 启动

正常使用请双击接入工具包的 `启动NPC动作.cmd`，然后在宿主插件面板启用ARDY并保存、重载。无需令牌或宿主命令行；服务仅监听本机。下面为旧开发环境调试入口。

从接入包目录进行开发调试（普通用户直接双击启动文件）：

```powershell
& ./start-npc-motion.ps1
& ./start-npc-motion.ps1 -Smoke
& ./start-npc-motion.ps1 -Check
```

独立插件源码中的兼容入口需通过 `-KitRoot` 指定接入包目录。模型、设备与缓存路径统一从接入包配置解析，不再复用开发者的环境或图缓存。

HTTP 默认监听 `127.0.0.1:2346`。模型加载和预热期间可读取健康状态，但 `ready=false`。关闭进程释放模型，不自动启动任何世界。

## 接口与状态

以下均为插件/执行桥的内部接口，不注册成主模型工具。除 `/health` 外均需要 Bearer 令牌；写请求拒绝浏览器 Origin。

| 接口 | 用途 |
|---|---|
| GET /health | 服务实例、加载状态、世界会话、取消代次、缓冲计数 |
| POST /world | 隔离桥刷新世界租约与版本；只接受 `mode=isolated` |
| POST /tasks | 显式提示词任务；要求 instance、session、epoch、request_id |
| POST /intent | 消费插件已编译的低频基础动作，不能抢占显式任务 |
| GET /tasks/{op_id} | 查询任务；生成结束只是 awaiting_world |
| POST /requests | 根据 session、request_id 查询不确定请求，不重新执行 |
| POST /chunks | 拉取一个待确认分段，重试返回同一分段 |
| POST /ack | 确认分段；最终只产生 isolated_completed |
| POST /cancel | 清空缓冲并使旧推理失效；不声称世界已停止 |

世界数据使用米、Y 向上、XZ 二维平面；`root` 为 `[x,z]`，`paths` 为语义目标到已验证路径点的映射，`revision` 单调递增。默认世界租约 2 秒，执行桥需持续刷新。路径或世界版本改变会取消当前任务；当前尚无真实地图采集桥。

任务缓存最多 128 项、分段缓冲最多 3 段，图重放历史保持 4 帧。幂等键在有限缓存范围内有效；即使旧缓存淘汰，旧代次和旧服务实例的提交仍被拒绝。任务超过目标时长加 10 秒也会取消。停止不等待 GPU，GPU 返回的旧段不会入队。

基础动作使用插件 `AutonomyIntentProvider` 的 description/style，经确定性编译后送入 `/intent`。重复快照不重新编码文字；正常完成可续期，失败/取消/未知状态不自动复活。单次 ARDY 任务仅编码一次文本，续段复用特征。新显式任务当前重置历史，跨任务骨架姿态衔接仍需第三阶段世界姿态反馈。

路径采样仅覆盖平面行走和原地动作；原地根轨迹偏差大于 3cm、移动根轨迹偏差大于 20cm 的分段拒绝入队。这不是脚滑指标，不代替落脚点、接触、碰撞、台阶或骨架标定。玩家目标、旧 action_key 家具交互尚未由此服务执行，明确拒绝。

## 验证结果与限制

- 服务协议与竞态测试见 `test_service.py`；真实 HTTP 认证、幂等、迟到结果、缓冲上限、租约、任务期限、完成回执、基础动作优先级均有覆盖。
- 插件候选完整回归：271 passed、1 skipped、292 subtests passed。
- 真实宿主 SDK 的差量注册与 IPC 队列序列化通过，停止入口在三次切换期间仅注册一次。结果见 `../host-sdk-probe.json`。接收端是隔离队列，不是运行中的主聊天会话；SDK 排队成功也不等于宿主最终注册确认。
- 优化模型实测见 `smoke-ardy-graph-result.json`：本次权重加载约 9.87s、预热约 44.42s；两个新任务首段约 1.72s/0.96s，两个续段约 168ms/159ms。每段 40 帧，20 FPS，可播放 2 秒。图重放计数实际增加。
- 同一次实测原地根轨迹最大偏差约 7.2mm/6.1mm，直行约 5.9cm/4.4cm。这些是少量模型输出样本，不是 Unity 脚滑、复杂场景或 30 分钟稳定性验收。
- 同一驻留真实模型完成 HTTP 基础动作受理、40 帧生成、拉取及 `isolated_completed` 回执，始终未宣称正式执行就绪。该有限实测直接驱动生成步骤；长期后台线程和实际世界消费速率仍需联调。

若取消 HTTP 请求超时，插件锁存 ARDY 不可执行，世界端 stop 仍独立发送。排障后重载插件恢复，不能仅凭服务重新在线自动解除这类不确定状态。

下一阶段需实现真实世界桥与碰撞/接触约束、根控制权互斥、目标骨架映射、多人同步，并取得真实 VRChat 终态回执后才允许 `execution_ready=true`。
