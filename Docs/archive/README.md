# 归档说明（Docs/archive/）

> **本目录是历史层，不是现状。** 这里的文档是**日期化实验报告**与**已被取代的结论**，
> 保留用于溯源，**不要当作"当前实现/当前真值"引用**。

## 检索规则

本目录被 `Docs/.ignore` 排除：

```bash
rg cam_h Docs/          # 只搜现役层 —— 第一屏就是答案
rg cam_h Docs/ -u       # 含归档，全量溯源
```

## 归档判定依据

每份文档被移入这里，是因为 `Docs/README.md` §三 索引**自己**给出了下列状态之一：

| 依据 | 说明 |
|---|---|
| `📁` / `⚠️📁` | 索引已标归档 / 已加【历史】标题 |
| `⚠️` | 结论已被后续文档推翻或取代 |
| `❌` | 已证伪出局 |
| 同主题被取代 | 该主题已有更新的权威文档（如 P0.1/P0.2/P0.3a → P0.3b） |

## 为什么原文一字不动

按本仓库既有规矩（`ROADMAP-历史实现记录` 抬头）：

> **被推翻的假设是证据，不要删。**

推翻的过程本身是方法论的产出 —— 例如"同一个 bug 数了两遍当交叉验证"、
"外部真值其实是记录器默认值"这类教训，只存在于这些报告的自我更正节里。

## 现役层在哪

`Docs/*.md`（顶层）＋ `Docs/README.md`（索引与检索协议）。
