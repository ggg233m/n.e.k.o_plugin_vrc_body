# YUI 面板中的 VMC 动作共享

在 YUI 插件管理面板的「动作来源」中勾选「VMC 动作共享（N.E.K.O → YUI）」，保存设置并重载插件。勾选 VMC 会自动取消 ARDY，反过来也一样；直接配置两者同时启用会被拒绝。两者都关闭时使用原动作系统。

VMC 是独立动作来源，不启动 ARDY 服务，不加载动作模型，也不依赖命令窗口或临时姿态文件。插件负责本机 UDP 39540 接收、宿主 VMC 开启和 T-pose 校准。宿主 3D 模型页面需要保持打开。世界须具备 pose_stream_v2 骨骼通道。

共享 19 个身体骨骼，转换为世界使用的 27 骨骼协议；不传输手指或表情，不移动水平根节点。每个 200 毫秒块采样一次宿主姿态，以原 10 FPS MIDI 通道播放。VMC 模式不提供 ARDY 生成动作工具。

面板区分接收状态、已接收帧数与世界播放状态。断流超过 0.5 秒会结束共享通道并交回原动作系统，不触发全局急停，也不会暗中切换到 ARDY。更换宿主模型后需要重载重新校准。

关闭开关并保存、重载后停止共享。停止、插件关闭或校准失败时，接收器释放 UDP 端口，并在宿主目的地仍由本接收器占用时恢复宿主原 VMC 设置；用户后来修改的目的地不会被覆盖。恢复失败会在面板显示。
