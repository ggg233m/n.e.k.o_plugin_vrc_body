# 行走约束、转弯与地面支撑修复

2026-09-12，Unity 主场景 ClientSim、真实 ARDY 与 NEKO_MIDI。没有启动 VRChat。代码和编译资产已经同步，但没有启用正式场景的持续能力。

## 结论修正

转弯倾斜不能直接当作异常摇摆。此前用整段最大躯干倾角否定500ms约束候选，混入了直角转向、停步转身以及转弯后的姿态延续，证据不足。本轮保留500ms候选，修正路径几何；没有通过夹紧躯干角度、扩大碰撞/接触容差或手动关闭注视来消除倾斜。

固定种子20260912的直线模型审计中，世界速度0.8m/s时，每帧固定根条件的躯干倾角P95为16.82°，500ms采样为11.54°；0.35m/s且逐帧固定时为35.20°。九组采样的根横向偏移最大约2.4cm，没有证据表明直线走路撞到了20cm路径走廊。它支持稀疏约束和速度会影响动作的判断，但只是单种子直线实验，不能代表所有转弯或动作质量。

## 修改与验证

- Root2D支持稀疏帧索引，路径每500ms约束根位置和朝向，保留连续历史；世界行走速度采用一致尺度的0.8m/s。MIDI包和逐帧校验未增加。
- 最短NavMesh路径常贴边，直接向内圆滑会切入不可走区域。世界先验证最多16cm的外侧余量及前后连线，再批准曲线切入长度；模型侧使用相切曲线、曲率限速和连续加减速。狭窄拐点仍可回退为停步转向。
- 路径请求失败返回明确结果并确认原控制票据，不再变成MIDI超时。
- 三维世界锚点和路径Y值保留，模型仍使用Root2D，世界执行器负责实际地面高度。接缝和地毯斜边使用有效支撑面复核；局部8cm高度、坡度门槛和胶囊碰撞保留。
- Python回归435 passed、1 skipped、301 subtests passed；曲线路径测试核对速度、加速度、朝向、走廊、连续过弯和未批准拐角回退。最终Udon编译无错误。
