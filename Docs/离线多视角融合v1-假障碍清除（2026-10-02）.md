# 离线多视角融合 v1 —— 假障碍清除（2026-10-02）

## 目的与结论

把逐格分类从"纯计数"升级为"观测质量分层"（近/中/远三带），验证**离线多视角融合能否清掉远场假障碍**。
结论：**能，且单独一层就打平在线 ray_clear 的效果**（044153 上 fused 11.1~13.3% vs 真 mapper 锚点 13.7~14.1%）；
但改善幅度受**位姿质量上限**约束——无回环修正的 0929 只清掉约 10 个百分点（36→26），有回环修正的 044153 清掉 20 个百分点（31→11）。
**位姿 >> 深度的杠杆排序被本次实验定量证实。**

## 方法（`.tmp/_fusion_v1.py`）

- 重放录制关键帧，与在线 mapper 相同的逐帧管线（体素化 5cm/2cm → R 旋转 → cam_h → `_ground_correction` 复用 → 高/地分类）；
- 每格计数按观测距离分带：**近 <1.5 m / 中 1.5~3 m / 远 >3 m**（base 系水平距离，与 `cov_near_m` 同源）；
- **baseline**：在线计数规则复刻（`O≥min_pts & O≥0.3G` + 3×3 多数），**不含** ray_clear——与 fused 同一条数据管线，隔离变量；
- **fused 规则**：
  1. 近距确认（`o_near≥3`）→ OCC（近场假障碍 0.06%，近看票即决定性；**故意不带**地面压制条件——恢复被 ratio 误杀的细障碍）；
  2. 中距多帧确认（`o_mid≥3` 且 ≥2 关键帧 且 `O≥0.3G`）→ OCC；
  3. baseline 判障但不满足上两条：有近/中距地面证据 → **FREE**（量化倾斜假障碍，清掉）；否则 → **UNK**（诚实降级，不伪造 free）。
- 评估：run5-7 同口径「已知内障碍%」= 障碍格/(障碍格+free 格)，轨迹距离环 R∈{1.5,2.5,3.0}。

## 结果（R1.5 / R2.5 / R3.0 的已知内障碍%）

| 口径 | 044153（397kf/218m，final_poses 回环修正） | 0929（3014kf/792m，kf T_map 无回环） |
|---|---|---|
| baseline（纯计数，无 ray_clear） | 31.4 / 31.2 / 30.9 | 37.0 / 36.3 / 36.0 |
| rmax3（RangeMax=3 复刻，run5-7 口径） | 28.1 / 28.0 / 27.9 | 36.2 / 35.9 / 36.0 |
| **fused（质量分层）** | **13.3 / 11.5 / 11.1** | **28.4 / 26.4 / 25.9** |
| 真 mapper 在线管线（计数+ray_clear，锚点） | 14.1 / 14.0 / 13.7 | — |

044153 转换明细：baseline 障碍 28112 格 → fused 9172；清成 free 15565 / 降级 UNK 4222 / 保留近距确认 8325 / **新增 847**（近距确认恢复的细障碍，故意设计）；被清格的障碍票 **80% 来自纯远距观测**——与量化倾斜机理吻合。free 面积 R2.5 内 42.6%→52.7%。

## 发现

1. **质量分层 ≈ ray_clear**：fused（无 ray_clear）与真 mapper（有 ray_clear）在 044153 上同量级（11~13% vs 14%），R2.5/R3.0 更优。两者机理正交（距离质量 vs 视线看穿），**离线固化档应叠加两者**，预期更低。
2. **RangeMax 截断不是好办法**：rmax3 与 baseline 差距很小（28 vs 31），丢远场信息只换来 unknown 暴涨（R2.5 unknown 55% vs fused 40%）——"丢弃"劣于"分层降级"。
3. **位姿是上限**：0929 用记录时位姿（尾部错位 5.459 m），多视角一致性被位姿漂移破坏，近距地面证据落不到远距声称的格上，清障能力减半（-10pt vs -20pt）。**这定量证明了 P0（回环/跨会话接线）优先于深度侧融合**。
4. **规则教训**：fused 中距确认最初漏了地面压制条件（`O≥0.3G`），0929 上新增了 10520 个假障碍格；补上后降到 6293。近距确认**故意不带**该条件（847 格为恢复的真细障碍）。
5. cam_h 全场常数估计（逐帧带内众数→跨帧加权中位）与本管线自洽；044153=1.756、0929=1.878（HMD 高度不同会话，合理）。

## 边界与下一步

- 本实验**不含**全分辨率重建（fx×4 误差÷4）、WLS、学习型匹配——都是固化档后续叠加项；
- 产物：`.tmp/fusion_v1/`（两场 compare PNG + metrics json）；脚本 `.tmp/_fusion_v1.py`（复用 `nav_mapping._ground_correction`，参数全在文件头）；
- 固化档接线时的路径：本分类器输出 → world 先验（`navmesh_memory/<world>/prior/`，原子写），三态语义与在线一致（fused 的 UNK 降级天然满足"宁可 unknown 不可伪造"）；
- 待办遗留：0929 若拿 P0 接线后的回环修正位姿重跑，预期清障能力恢复到 044153 水平——这本身就是 P0 价值的又一条实测证据。

## 2026-10-06 更新 —— 工具收编 + "merged vs rigid" 实测（P0.3b 下一步②）

- **收编**：`research/tools/offline_fusion.py`（位姿源 `--pose auto|final|merged|rigid`；录制名与会话 sid 不同时用 `--session` 指名）。
  **自检**：`--pose final` 在 044153 上**逐位复现**本文数字（baseline 31.35/31.20/30.90、rmax3 28.10/27.95/27.90、
  fused 13.33/11.53/11.13，转换明细 28112→9172 全同；fusion 7.2 s）。
- **A/B**（`final` = 录制自带 final_poses；`merged` = 已采纳表；`rigid` = 原表只加并树的刚体分量），「已知内障碍%」取 R3.0：

  | 会话（位姿） | baseline | fused | 非刚体残余（中位） |
  |---|---|---|---|
  | 044153 final | 30.90 | 11.13 | — |
  | 044153 merged（10-03，135 锚） | 30.83 | **10.39** | 2.30 m |
  | 044153 rigid | 31.07 | 11.05 | — |
  | 235237 final | 29.05 | 10.64 | — |
  | 235237 merged（10-06 桥，19 锚） | 53.34 | **19.41** | 2.54 m |
  | 235237 rigid | 28.95 | 10.55 | — |
  | 001523 final | 29.30 | 10.01 | — |
  | 001523 merged（10-06，199 锚） | 48.11 | 11.19 | 1.45 m |
  | 001523 rigid | 29.23 | 9.97 | — |

- **结论（把本文"位姿是上限"读细一层）**：
  1. `rigid` 与 `final` 逐位同级 ⇒ **刚体换系对融合零代价**（工具守恒自检；也说明该指标只看会话内部几何）；
  2. merged 的收益是**有条件的**：原始位姿内部有病的会话（044153 尾段）被修好 ⇒ fused 改善（11.13→10.39）；
     而**内部早已自洽**的会话（post-loop 的 235237 / 001523），并树的**弹性形变**（非刚体残余 1.4–2.5 m）
     反把多视一致性拉坏 ⇒ 假障碍率近乎翻倍（235237 fused 10.64→19.41、baseline 29→53）；
  3. ⇒ **离线融合 / 固化档应默认 `--pose rigid`**（只换系、保会话内部形状）；merged 的弹性形变留给
     "内部形状不可信"的会话（无回环的老录制，如 0929 / 045615）。世界索引 / 重定位继续用 merged，
     不受影响（它要的是跨会话一致，不消费会话内部形状）。

## 2026-10-06 更新三 —— live 首场抓到"注入了一张废图"（闸门加了前后半交叉验证）
