# OSC 速度尺度与回访拖影（2026-10-12）

> 📊 日期化实验记录。当前值以 [`FACTS.md`](FACTS.md) 为准。
> 代码状态：`a1504f6`（`osc_speed_scale` 默认 0.85 已提交）。复现脚本都在 `.tmp/`（未入库），见 §七。

## 结论先行

1. **OSC 速度积分比真实位移多 15–20%**。`world_scale 0.755` 是对的，错在 OSC 一侧。修法是给 DR 的速度乘系数，已落地为 `OnlineNavConfig.osc_speed_scale = 0.85`（`backend/nav_online.py:62`）。
2. **系数修的是"地图被放大"，修不了用户看到的弧形拖影**。拖影是**不同经过**（回访）之间的墙错开，回环后中位仍有 17–28 cm，k 取 1.0/0.85/0.80 几乎无差。
3. **回访墙平面约束位姿图判否**。墙法向留出偏移降 28–57%，但回访全几何倒角不变，栅格走廊障碍 −35%~+27%，有场次变坏。
4. 两条口径教训：`smear_eval` 的"最大竖直面"常拟合到地面（数字作废）；评估跨经过对齐**不能只看被约束的那一维**。

## 一、尺度错在哪：三路独立证据

### 1.1 相邻关键帧 ICP（`.tmp/icp_fwd.py`）

相邻关键帧（隔 2），只用迎面墙做 2D 点到线 ICP，只解平移，旋转用 HMD。视觉/DR 前向平移比的中位：

| 场次 | 视觉/DR |
|---|---|
| 20261010_033237 | 0.819 |
| 20261001_044153 | 0.870 |
| 20261005_235232 | 0.834 |
| 20261006_001019 | 0.851 |
| 20261006_001523 | 0.852 |

- 三个速度档几乎相同（033237：0.83 / 0.81 / 0.82），横向 ≈0 ⇒ **纯尺度错，不是时延/超前项**。
- 非引导 ORB PnP 给出 0.81–0.87，一致。
- ⚠️ **引导匹配**的 ORB（`kf_visual_odom` guided）给 0.93 且随速度变：引导半径按 DR 预测取，结果被拉向 1。**别用引导匹配估尺度**。

### 1.2 排除项

- DR 积分本身：原始 OSC 重积分 / `T_dr` 步长 = 1.000–1.007（`.tmp/dr_reint.py`）。
- avatar / 身高：用户确认未换。
- 双目远处压缩：地面峰随距离 1–5 m 只变 0–2%（`.tmp/gnd_vs_z.py`）。
- "各场眼高不同"：是我口径用错。5 场 `cam_h − gc` 都在 1.745–1.766 单位。各种"眼高"口径的区别见 `漂移形态诊断（2026-10-05）.md` §10.8–10.10。

### 1.3 尺子标定录制（`run8_ruler`，`.tmp/run8_*.py`）

数据里分不清是 OSC 错还是双目错，所以在尺子房间录了一场：先对着尺子静止，再沿尺子直线跑。

- 近处（0.7–1.5 m）尺子真距 / 双目深度 = **0.757** ⇒ `world_scale 0.755` 对。
- ∫VelocityZ 对尺子 ΔZ 拟合（每段自由 Z0）：s ≈ **1.16**（按 DR 同号 0.18 s 超前）到 **1.20–1.25**（残差最小，τ≈0.10–0.14 s）⇒ **OSC 多算**。
- 镜头已停（尺子读数不变）而 VelocityZ 还要 0.3–0.4 s 才线性降到 0；稳速 4.0 时镜头实际约 3.4–3.8 m/s。
- 净位移（静止→静止）测不了尺度：来回走会把误差抵消。

⇒ 修 DR，不动 `world_scale`。

## 二、乘系数后的效果（`.tmp/kscale_loop.py`）

DR 对速度是线性的，所以 `osc_speed_scale = k` 等价于 `T_dr` 的 xy 与 `dist_m` 同乘 k。再用当前默认 `LoopConfig` 重跑回环，得到 `<rec>/lkNNN.npz`。

### 2.1 栅格（`grid_pose_ab`）

| 场次 | 走廊障碍 lk100 → lk085 → lk080 | 墙厚 m（lk100→085） | 自由格 lk100→085 |
|---|---|---|---|
| 044153 | 999 → 701 → 597 | 0.28 → 0.20 | 63568 → 54467 |
| 235232 | 849 → 623 → 530 | 0.28 → 0.28 | 87881 → 73287 |
| 001019 | 1464 → 1011 → 847 | 0.28 → 0.28 | 70948 → 57016 |
| 001523 | 742 → 506 → 384 | 0.28 → **0.40** | 56185 → 47287 |
| 033237 | 869 → 419 → 344 | 0.28 → 0.20 | 97996 → 81404 |

- 走廊障碍按路程归一后：k=0.85 −14~−43%、k=0.80 −22~−50%。
- 自由格 −13~−22%，这是**纠正放大**，不是丢地图。
- 001523 墙厚变坏（0.28→0.40）。
- `可走m²` 列输出 `None`，指标未修。

### 2.2 墙面失配（严格口径，见 §四）

- 相邻帧朝墙带符号偏差：DR +10–15 cm → ×0.85 后 +5–10 cm ⇒ 系统偏差确实被去掉一半以上。
- 但 |整面偏移| 中位只降 0–2 cm（001019 12.9→10.6）。
- 偏移随帧间法向位移涨：dn<0.15 m 约 7 cm，>0.8 m 时 18–30 cm；变速、转身 ≥15° 时更大 ⇒ 剩下的是**逐段随机的 DR 误差**，常数系数修不掉。

## 三、用户看到的弧形拖影 = 回访错位（`.tmp/smear_revisit.py`）

用户说"k=1.0 和 0.8 看不出区别"。按时间着色后看清：弧形拖影是**不同经过**的墙错开（颜色不同），不是相邻帧。

回访对：Δt>10 s、相机距离 <1.5 m、朝向差 <45°；严格口径墙面偏移中位：

| 位姿 | 033237 | 001019 |
|---|---|---|
| DR | 108 cm | 52 cm |
| lk100（= bow4） | 18 cm | 28 cm |
| lk085 | 17 cm | 27 cm |
| lk080 | 21 cm | 28 cm |
| final_poses（在线会话表） | 34 cm | — |

- **k 对回访错位无效**。回环已经把跨经过的大误差压掉，剩下的不是尺度。
- 回访同墙夹角（`.tmp/revisit_yaw.py`）：DR 8.5°、lk 4.2°、在线 6.6°，相邻帧噪声底 3.0°。墙在 3 m 外时 4° ≈ 20 cm ⇒ 剩余拖影里旋转占不小比重。
- 但回环 PnP 与 HMD 的偏航差中位只有 0.65–1.35°，且不随时间累积（`.tmp/loop_yaw_drift.py`）⇒ 偏航本身不漂，夹角更可能来自墙面拟合/关联噪声。
- ⚠️ 点云查看器默认用 `navmesh_memory` 会话表（= final_poses），比 lk100 差一倍。目视比较时注意选对位姿源。

## 四、口径教训：`smear_eval` 的"最大竖直面"常是地面

- `research/tools/smear_eval.fit_vertical_plane` 默认 `max_vz=0.35`：法向倾角中位 14.4°、p90 20.2°；内点过半在地面附近的平面占 34%（033237）。
- 后果：同面直线对的"墙距差 / DR 位移"中位只有 0.03–0.27（朝墙应 ≈1）⇒ 拟合到的多是随人移动的地面切片。早先"墙面失配 19–34 cm、k 改善不明显"的数字**作废**。
- 严格口径（`.tmp/smear_strict.py`）：只取离地 0.3–1.6 世界 m 的点，|nz|<0.06（倾斜 ≤3.4°）。5 场 |整面偏移| 中位 DR 12.4–15.8 cm、p75 31–43，自厚 3.0–3.5 cm；视觉/DR 0.81–0.88，与 §1.1 一致。

## 五、回访墙平面约束位姿图：判否（`.tmp/plane_graph.py`）

### 5.1 做法

在 lk085 的回环位姿图（DR 里程 + PnP 回环）上，加"回访同墙沿法向"一维约束 `n·(x_b − x_a) = 目标`。同墙关联用当前位姿下的整面中位偏移，σ=5 cm，Cauchy IRLS，外层重关联 3 轮。70/30 随机留出回访对做验证。变体：σ 10/20 cm、同侧判据、每帧再加第二面非平行墙（`pg085s05t`）。

### 5.2 被约束的那一维确实变好

- 留出回访对墙法向偏移：5 场 14–28 → 9–12 cm（033237 17.9→12.3、235232 28.4→12.3）。双墙版略好。
- 位姿相对 lk085 平移中位 22–36 cm、最大 0.6–1.4 m；相邻帧相对变化中位 1 cm ⇒ 是整段平移，没有把轨迹弄碎。

### 5.3 但整体没有对上

回访对全量 2D 倒角（障碍带 0.25–1.8 m 全部点，5 cm 体素，同一组对；`.tmp/revisit_chamfer.py`）：

| 场次 | 对数 | lk085 中位 / p75 | pg085 | pg085s05t |
|---|---|---|---|---|
| 044153 | 28 | 20.6 / 48.6 | **9.6** / 48.0 | 9.5 / 48.0 |
| 235232 | 137 | 12.5 / 52.5 | 12.6 / 51.7 | 14.6 / 54.5 |
| 001019 | 173 | 9.0 / 31.2 | 10.0 / 30.3 | 10.1 / 27.1 |
| 001523 | 131 | 7.2 / 24.2 | 7.2 / 24.7 | 7.8 / 24.6 |
| 033237 | 214 | 11.1 / 30.6 | 11.3 / 34.6 | 11.6 / 32.1 |

（单位 cm。>15 cm 的对在所有版本都占 36–49%，044153 从 61% 降到 43%。）

- 只有 044153 真变好；其余 4 场持平或略坏 ⇒ **墙法向这一维对上 ≠ 整体对上**。约束把墙拉齐了，同时把别的东西扯歪了（关联到平行的另一面墙或家具面、或只约束了一维）。
- 栅格走廊障碍：235232 −35%、044153 −5%、001019 持平、001523 +6~+10%、033237 **+27%**；044153/033237 墙厚 0.20→0.28 变坏。
- 033237 新增的走廊障碍格按关键帧归因（`.tmp/corr_diff.py`），分散在全程，不是少数坏帧。
- 加约束后回环残差略升（033237 中位 14.9→17.1 cm）⇒ 墙约束和回环约束在打架。

### 5.4 排除"双目深度随距离有偏"（`.tmp/wall_dist_bias.py`）

若深度随距离偏，同墙偏移应 ∝ 两帧到墙距离差 Δd。033237 corr **+0.02** ⇒ 排除。另两场的负相关可由位姿误差本身产生（离墙远的那帧位姿错得多），不算证据。

### 5.5 判定

判否。单墙/双墙法向约束不能修跨经过错位。这和 `点云拖影修复原型与栅格影响（2026-10-09）.md` §九、§十一、§十二 的结论一致：**跨经过对齐目前没有可用的约束源**。
