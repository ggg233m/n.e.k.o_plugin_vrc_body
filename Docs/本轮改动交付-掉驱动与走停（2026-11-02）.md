# 本轮改动交付（2026-11-02）

> 三件事**已实测证实**并落地；第四件（路径输入）**已实现但效果未验证**，默认关闭。

## 一、掉驱动：根因找到并修复

**根因**：`PolicyRuntime(graph=True)` 把 `SYCL_UR_USE_LEVEL_ZERO_V2=1` 写进父进程
`os.environ`（`policy_runtime.py:90`），而 LAS2 子进程的环境是 `dict(os.environ)`
**整份复制、零过滤**（`stereo_backend.py:277`）。于是 LAS2 也切到 Level-Zero V2 适配器，
一块 A770 上两个 V2 客户端抢同一个 compute context。

触发不是偶发竞态，有一条**确定命中**的路径：`prewarm_shape()` 是猜的，猜不中时会话首帧
会重建子进程，那次重建 100% 发生在 policy 初始化之后。

**修法**：`_XPU_POLICY_ONLY_ENV` 白名单剔除四个键。

**判决实验**（`.tmp/verdict-driver-2026-11-02.md`）：

| 组 | 配置 | 时长 | LAS2 帧 | timeout | 崩溃 | policy p50 |
|---|---|---|---|---|---|---|
| R1 | V2 + eager + LAS2 | 15 min | 8697 | 0 | 0 | 290-400 ms |
| R2 | **V2 + 图重放 + LAS2** | 16 min | **9538** | **0** | **0** | **164 ms** |

V2 已确认真的生效（`platform_name` = `...over Level-Zero V2`）。

## 二、走停：相位错位修复

**根因**：`obs_t` 在**推理前**打戳（`policy_runner.py`），而执行器按 `k = age/0.1` 取步
（`policy_executor.py:121`）。块到手时 age 已等于整段推理延迟，`k` 直接从 L/0.1 起步 ——
**块的前几步永远不执行**，而生产配置下那一窗正好是模型的负速谷底。

**修法**：`obs_t` 改用**图像采集时刻**（`captured_at_source`）。

**实测**：

| 指标 | 修复前 | 修复后 |
|---|---|---|
| `frame_age_ms` | 0 | **47.9 / 69.0** |
| halt 次数 | 340（刷屏） | **0-1 / 75-115 样本** |
| 轴值归零 | 反复 | **0** |

## 三、速度：恢复模型本意

`VRC_POLICY_VMAX` 从 1.0 放开到 4.0（满轴不封顶）。

| VMAX | 策略实际速度 | A* 对比 | 触顶比例 |
|---|---|---|---|
| 1.0 | 1.00 m/s | 慢 3.6x | 90%（被压死） |
| 3.0 | 2.36 m/s | 慢 1.5x | 17% |
| **4.0** | **2.83 m/s** | **慢 1.37x** | 少量 |

放开后模型自己也没跑满 4.0，说明 2.83 m/s 是它真实的意愿速度。

## 四、路径形状输入：已实现，效果未验证，默认关闭

**动机**：VLA 只拿 `local_goal` 一个前视点，与 pure-pursuit 用**同一行代码**
（`nav_follow.py:224` vs `:200-203`）。信息集相同 ⇒ 轨迹必然是 A* 的时间重参数化。

**实现**：`path_ahead()` 给出沿路径前进的 k 个机体系点，写进 prompt（`PROMPT_PATH`）。

**为什么默认关闭**：训练集里**没有这些 token**，模型没学过怎么用。这个 A/B 只能验证
「信息确实喂进去了」，**不能验证任何效果** —— 真要让它学会用，得按同格式重训。

开关：`VRC_POLICY_PATH_IN=1`（默认 0）。

## 五、顺带修的两个真 bug

1. **`cmd.exe` 用 GBK 读启动脚本，UTF-8 中文注释吞掉下一行** —— `set VRC_POLICY_HEAD=1`
   被吃掉，策略头静默不启动，日志里一个字都没有。启动脚本已改纯 ASCII。
2. **`policy_runner` 的 numpy 真值 bug 同款** —— `0 if not path else len(path)` 对数组
   求布尔会抛 ValueError。改成 `path is not None`。
3. **`process.py` 零 logging 配置** —— `self.logger` 是 None，装配失败的警告彻底消失。
   已改成同时写 stderr，并把原因存进 `_policy_start_error` 由 `/policy/state` 外显。
