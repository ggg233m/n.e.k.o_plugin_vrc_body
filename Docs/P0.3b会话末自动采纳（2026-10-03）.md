# P0.3b 会话末在线自动采纳（2026-10-03）

## 一句话

`stop()` 时 write_back 成功后，后台线程自动跑跨会话采纳（gauge + 弹性位姿图），
结果进 `status()["xsession_align"]`——**"会话末固化先验"闭环的最后一公里**。

## 接线结构

```
stop() → _end_memory() → _end_xsession()
           └ write_back 成功 ⇒ spawn navmesh-xsession-align 线程（daemon）
                └ align_into_auto(world_dir, sid, cfg)
                     ├ 读 constraints.jsonl，按 old_sid 计数挑最多者
                     ├ < align_min_constraints(8) ⇒ ok=False 跳过（不硬凑）
                     └ align_into()：gauge 初值 → 弹性锚定位姿图 → 留出验证 → 落盘
```

- **代码下沉**：对齐管线从 `tools/xsession_align.py` 下沉到 `backend/nav_xsession.py`
  （`align_into` / `align_into_auto` / `_elastic_merge`），tools 变薄壳，在线/离线同一条路径。
- **产物不变**（`xsession/` 下与原表并存）：`align_<new>_into_<old>.json` +
  `merged_<new>_into_<old>.npz`。不碰 `sessions/*/poses.npz`。
- **status 契约**：`xsession_align` = `{state:"pending"|"running"}` 或结果
  （ok/gauge/train/holdout/moved_m/reason）。对齐失败只进 errors 列表，不影响 stop。
- `XSessionConfig` 新字段：`align_min_constraints=8`、`align_tail_m=100`、
  `align_holdout_frac=0.3`、`align_elastic=0.15`。

## 顺带修掉 estimate_gauge 的一个真实弱点

合成测试暴露：外点重污染时（首轮内点残差被抬到 0.78 m > 0.5 m 阈值）**全体被剔
→ keep<3 → 放弃收敛**。修法 = 剔除阈值渐进收紧：`tol = max(pos_tol, 残差 60 分位)`
——首轮保住多数派，后续轮收到目标阈值。

真实数据回归：044153→013519 复跑，**下游优化结果逐位不变**（留出 med 0.486 m），
gauge 内点 66→81（初值更稳），R_dev 4.15→4.28°。修复只影响原本会放弃的退化场景。

## 已知局限（测试注释与报告同步记录）

- **末端单侧链**：最尾帧无后继锚，插值修正约一半（合成末帧 2.5 m/漂移 5 m；
  真实 044153 留出 p90 4.95 m 同源）。锚密度是关键变量。
- **首漂移会话冷启动**：首个会话没有历史可对齐（auto 返回 no_constraints），
  第二个会话起才生效。
- 对齐用的约束来自本次会话实时确认（在线 HMD yaw 门把关），025013 类坏会话
  会被 yaw 门挡在约束生成阶段，不进对齐。
