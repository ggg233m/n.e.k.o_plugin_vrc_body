`tools/xsession_align.py`，产物落 `xsession/` 目录与原表并存——**"会话末固化先验"的第一块砖**。

## 工具：`tools/xsession_align.py`

```
python tools/xsession_align.py --world wrld_home-7cf435ea \
    --new 20261001_044153 --old 20261001_013519
```

流程：约束过滤（old_sid 匹配）→ `estimate_gauge` 刚体初值 → 弹性锚定位姿图
（节点=x/y/yaw，z 不动；里程边 σ=0.05+0.15·step；scipy trf 稀疏 + IRLS Cauchy）→
尾段（>100 m）锚按 new_kf 分组留出 30% 验证 → 产物落盘。

**产物（均在世界 `xsession/` 下，不碰 `sessions/*/poses.npz` 原表）：**
- `align_<new>_into_<old>.json`：gauge（R_G/t_G/R_dev）、优化与留出统计、逐锚内外点掩码；
- `merged_<new>_into_<old>.npz`：修正整表（ids/T_map/dist_m + base_sid/method 元数据）。

## 复现验证（044153 → 013519，与 P0.2 实验一致）

| 指标 | gauge 初值 | 优化后 |
|---|---|---|
| 训练锚 (n=127) | med 0.475 / p90 2.080 m | **med 0.212 / p90 1.636 m** |
| 留出锚 (n=8) | med 6.273 / p90 9.720 m | **med 0.486 / p90 4.952 m** |

形状保持：头段位移 med 0.34 m（基本不动）、尾段 med 5.24 / max 6.45 m（被拉回锚位）；
相邻步长变化 med 1.5 cm（>5 cm 步段相对 3.1%），无折叠。运行 15 s / 397 节点。

**merged 表 sanity 全过**：ids 与原表逐位一致、z 严格未动（max 差 0.0）、
R 正交性 2.2e-16、det=1。与 P0.2 实验数字同级（留出 med 0.486 vs 0.552，
差异来自 yaw 边弹性系数实现细节，结论不变）。
