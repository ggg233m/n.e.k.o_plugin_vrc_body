# 受控录制通道自检清单（一页）

用途：正式录完整路线**之前**，先做一次短录制，确认**所有通道真的在写**、时间基准对齐，避免再拿到一份"没有动作日志"的素材。配套工具：`research/tools/check_recording_channels.py --run <run_dir>`（只读，全 PASS 才退出 0）。

---

## 一、短录制该走哪几个动作（建议 60–90 s）

> 关键前提：VRChat 速度回传是**变化驱动**——**静止不发包，匀速也可能不发包**。所以"有没有 OSC 报文"本身不能区分"站着不动"和"匀速前进"。短录制的目的就是亲手造出可对照的报文现象。

| 动作 | 该看到的报文现象 | 通道证据 |
|---|---|---|
| **① 静止几秒**（出生点站立） | OSC 出现长空档：无 VelocityX/Z 报文；HMD 有 `rotation_xyzw` 但 yaw 基本不变 | `osc.jsonl` 洞、`hmd_frames.jsonl` 帧在但转角≈0 |
| **② 持续匀速几秒**（一路向前） | `VelocityZ>0` 且较稳定；但注意——匀速段**也可能不出报文**（同静止一样是洞）；`action_timeline` 此刻必须记着"在前进" | 对照 `action_timeline` 的 `input_command.forward` |
| **③ 明确停止几秒**（从匀速→0） | VelocityZ 出现一次归零/跳变；与②"匀速段"的洞形成**对照**：同样是无报文，②是真在动、③是真停住 | 用 `action_timeline` 区分，不能只靠 OSC |
| **④ 原地转头各一次**（左右各一次） | HMD yaw 出现明显转角（`rotation_xyzw` 变化），但 Velocity 仍空——**转身 100% 落在报文洞里** | `hmd_frames.jsonl` 有转角、`osc.jsonl` 仍空 |

**为什么必须含 ②+③ 对照**：只有"持续匀速"和"明确停止"摆在一起，才能验证"洞=停住"这个口径假设；否则匀速段的洞会被误当成静止。**"走过一段距离"只能排除"原地转头"，不能单独证明"回到同一地点"**（回环要靠重访证据，不是里程）。

**短录制后立刻跑自检**：`research/tools/check_recording_channels.py --run <短录 run>`。要求 `osc` / `hmd_frames` / `run.json` 锚点 / `action_timeline` / `video_timebase` 五项全 **PASS**。任一 FAIL 就别录完整路线，先排障（见操作手册 §6 常见坑）。

---

## 二、完整路线录制前的检查项

1. 插件后端已停（释放 9001），VRChat OSC 输出端口=9001。
2. OBS WebSocket 已开，录像 1920×1080@60fps mkv 存 `F:\obs`；用 `--obs` 录（否则 `obs_start_monotonic` 为 null，整条链废）。
3. 路线文件用 `--route-file`（缺口 B 已补，别再录死方形）；开头/结尾留 `--settle-s` 静止段。
4. AnyaDance 驱动注册、SteamVR 虚拟模式、`command_log_enabled=true`（v2.1 手动 HMD 采集需要，否则 `hmd_frames=0`）。
5. 开录先做一个**标志性动作**（原地快速左右看一圈）当时间线信标。
6. 录完跑自检工具，**全 PASS 才进后处理**；并记下**报文新鲜度**（`coverage_frac` / `max_gap` / `zoh-stop` 落差）。

---

## 三、四臂对照验收 4 点（记录在新素材上）

1. **时间基准对齐**：视频 / OSC / HMD / `action_timeline`（真实发送动作）按同一可复核基准对齐（`obs_start_monotonic` + `video_timebase.offset_s`，offset 逐 run 实测、不写常数）。
2. **B/C 臂真用了路线证据**：B/C 的路线历史确实来自 `action_timeline`，**未降级 `visual_proxy`**（无日志才降级，有日志但路径错应报 `missing` 而非 `absent`）。
3. **覆盖三类地点**：真重访（A→B→A）+ 视觉相似但不同地点（hall↔pooldeck / hall↔statue）+ 停留转头（同地点不同视角）。
4. **独立标注地点真值**：人工标地点 GT，比较 **A0 裸几何 / A1 几何+共识 / B 路线硬门 / C 联合评分** 的正确接受 / 错误接受 / 拒绝。

> 新素材**必须**含"持续匀速"+"明确停止"对照，并记录报文新鲜度（`coverage_frac`、最大洞、`zoh` 与 `stop` 口径落差）。允许负结果——**不**以升级 `confirmed_place_identity` 为验收条件。
