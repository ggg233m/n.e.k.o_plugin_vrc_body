## 1. 前置条件（每次录制都要确认）

1. **插件后端必须停掉**：它占用 `127.0.0.1:9001`，录制器绑不上会直接退出
   （脚本会提示"9001 可能已被插件后端占用"）。
2. **VRChat 已启用 OSC**，且 OSC 输出端口为 **9001**（默认）——否则收不到任何回传。
3. **OBS 已开 WebSocket 服务器**（工具 → WebSocket 服务器设置，默认端口 4455），
   录像设置与旧素材保持一致：**1920×1080 @60fps，mkv，保存到 `F:\obs`**。
4. 进世界后让 avatar **站立、不在坐姿/不悬空**；出生点即路线起点。
5. 用 `--obs` 录（否则锚点为 null，视频↔OSC 对不上）。

## 3. 路线编排（缺口 B 补齐后）

目标：**同一 run 内**覆盖视觉歧义，做同 run 四臂对照：

- `hall → pooldeck → hall`（去程经过 pooldeck，回程再经过一次 hall）
- `hall → statue → hall`（statue 几何不足 p50=16，专门考验"不自动合并"）

表达方式（建议的 `--route-file`，JSON 数组，按序执行）：

```json
[
  {"forward_s": 4.0, "turn_s": 1.1, "turn_value":  0.55},
  {"forward_s": 6.0, "turn_s": 0.0, "turn_value":  0.0 },
  {"forward_s": 4.0, "turn_s": 1.1, "turn_value": -0.55},
  {"forward_s": 6.0, "turn_s": 0.0, "turn_value":  0.0 },
  {"forward_s": 0.0, "turn_s": 2.2, "turn_value":  0.55}
]
```

- 每段＝先直线后转向；`turn_s=0` 表示纯直行。
- 转向标定已知：`LookHorizontal` **非线性**（实测 2.2×/4.2×，勿当作线性积分器），
  1.1 s @0.55 ≈ 90°；轴值请保持 ≤0.6（更高会削顶）。
- **不要求总转向 360°**——回环来自"重访"，不是几何闭合。
- 开头/结尾各留 `--settle-s 2.0` 静止段（出生点静止是"起点=终点"的自然标记）。

## 6. 常见坑

| 症状 | 原因/处理 |
|---|---|
| 绑定 9001 失败 | 插件后端在跑 → 先停掉 |
| `osc.jsonl` 全程没有 VelocityX/Z | VRChat OSC 未启用/输出端口不是 9001；或整段没动（按变化发送） |
| 锚点 `obs_start_monotonic=null` | 没加 `--obs`，或 OBS WebSocket 没开/密码不对 |
| 转向角度不对 | `LookHorizontal` 非线性（2.2×/4.2×），勿按线性外推；轴值 ≤0.6 |
| 录像时长 ≫ OSC 时长 | 正常（录像含前后闲置）；只要两端对齐到锚点即可 |
| 每条腿时长漂移 | 正常（按速度闭环），但 `legs` 的 `duration_s`/`avg_speed` 会记进 run.json |

## 7. v2 增补（09-20 晚：HMD 指南针通道，详见报告 §22.19）

> 本节是 09-20 讨论后的计划升级，**v2 录制按本节执行**；上文 1–6 节中与 `LookHorizontal`
> 相关的转向描述对 v2 **作废**。

### 7.1 通道纪律（v2 核心变化）

| 用途 | v1（作废部分） | **v2** |
|---|---|---|
| 转向 | OSC `LookHorizontal`（失真 2.2–4.14×） | **虚拟 HMD yaw 推帧**（零失真，推多少转多少） |
| 平移 | OSC `/input/Vertical` | 不变 |
| 路程 | `hypot(VelocityX,VelocityZ)` 时间积分 | 不变 |
| 避障 | 撞墙即提前转段 | **横移绕行**（`/input/Horizontal`，不改朝向，不依赖转角精度） |

**硬纪律：同一 run 内转向只走 HMD 通道**——两通道叠加且其一失真，混合即污染
（与"AngularY 不参与朝向积分"同一条纪律）。

### 7.2 前置条件增补

- 除 §1 全部条件外：**AnyaDance 驱动已注册、SteamVR 全虚拟模式启动**（推 HMD 帧的前提）
- 确认无手柄/头显 recenter 事件（recenter 会打断朝向连续性）

### 7.3 录制开头两件事（顺序固定，共约 1 分钟）

1. **扫视信标（约 1 s）**：推 HMD yaw 快速 ±45° 来回一次——已知单调钟时刻 + 视频显著
   视觉事件 ⇒ 视频↔单调钟独立交叉锚点（校验 OBS 锚点）
2. **90° 指南针验证**：推 HMD yaw +90° → 前进 2 s → **三条同时成立才算通过**：
   - 视频里视角恰好转了 ~90°
   - `VelocityZ > 0`（本地前向有速度）
   - `VelocityX ≈ 0`（没有侧滑）
   失败 ⇒ 停止录制，先排查（平移方向设置项 / 身体跟随死区 / 推帧时序）
